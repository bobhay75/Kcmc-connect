# KCMC Connect

Source repository for the Kimberling City Methodist Church Connect App.

The deployable application is in `KCMC-Connect-Phase6-Recreated/`. Version 3 adds individual member accounts, members-only prayer, pastor approvals and a recovery role that is intentionally blocked from prayer content.

The local, approval-gated worship-slide builder is in `contest-service-agent/`. It searches an approved private PowerPoint archive, reuses editable slides, creates missing slides only from authorized supplied lyrics, assembles a complete 16:9 service deck, runs QA, and stops for human approval. It does not publish or send anything.
