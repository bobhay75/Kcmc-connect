# KCMC handoff branding direction

The church website is the primary reference for the KCMC Connect hero, logo and theme. The app should match the website logo or complement it closely; compare the church's Facebook branding as a secondary reference. Use genuine church-provided branding and photographs, and preserve the church's identity.

The public church website at https://www.kimberlingcitymethodist.com/ includes a church logo. Facebook branding could not be verified in the October 26, 2026 public retrieval because Facebook throttled the request; do not claim a match until it is visually checked. The live app and the Git candidate differ in their hero presentation, so neither should be assumed to be the approved final design.

Before handoff, visually inspect the actual logo and website styling, compare with the Facebook page where accessible, and prepare the hero and theme against those references. Verify on phone and desktop, and check with the host baseline before any deployment. Retain the user's separate basic-handoff scope: no Publisher, member functions, smart clock, sermon assistant or other extras.

## Website visual inspection

The website header visibly uses the church's turquoise-to-deep-blue bridge-and-cross wordmark, on a light background. Its page typography and buttons use dark green with pale neutral backgrounds. The live app currently uses a blue-and-gold fish hero. A repository image `assets/visuals/kcmc-bridge-logo.jpg` visually resembles the website's wordmark, but exact source identity, current host availability, and intended permissions remain to be verified. Build a phone-and-desktop preview that complements the website before replacing the live hero. The website logo itself includes a stylized bridge; earlier leadership feedback requested no bridge art, so this specific logo choice must be presented clearly in the preview rather than treated as church-approved.
