KCMC CONNECT — VERSION 3.0.2
============================

Runtime:
- Apache + PHP 8.1 or newer
- HTTPS required in production
- JSON content and private stores; no database required

Public experience:
- Public church information, worship, watch, visit, events, news, serve and giving
- Installable PWA with explicit public-route network-first caching
- Public Prayer & Care page contains no request form and no prayer details
- Newsletter information is app-native text; complete newsletter page photographs are prohibited
- Separately approved individual ministry photos are allowed outside the newsletter-source directory

Private experience:
- Individual invited email/password accounts
- Member prayer submission and pastor-approved members-only prayer wall
- Confidential prayer-team inbox
- Each Pastor administrator uses a separate invited account
- Recovery administrator can maintain publishing and access but cannot access prayer content

Security controls:
- Role authorization on every private route
- Secure session cookies, CSRF validation and login throttling
- One-time, seven-day invitation tokens stored only as hashes
- Private, unknown, API/data/backup and token-bearing routes stay network-only and receive no offline fallback
- Private routes use no-store/noindex headers and bypass the service worker
- Private data and backups are denied by Apache and preserved during deployment
- Audit events never intentionally include prayer text, passwords or raw invitation tokens

First run:
1. Set server-only KCMC_SETUP_KEY.
2. Create the recovery administrator at /admin/setup.php.
3. Remove KCMC_SETUP_KEY.
4. Invite each Pastor administrator separately.
5. Complete the privacy checks in DEPLOY.md before member rollout.
